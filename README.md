# La Cabina con Luz

Sitio editorial de noticias, entretenimiento y fotografía para **La Cabina con Luz**, en colaboración con **Carmona Pics**.

## Sitio publicado

[la-cabina-con-luz.vercel.app](https://la-cabina-con-luz.vercel.app)

Código fuente: [github.com/Programer21777/la-cabina-con-luz](https://github.com/Programer21777/la-cabina-con-luz)

## Características

- Portada editorial adaptable a computadora y celular.
- Buscador y filtros por categoría.
- Secciones para noticias, agenda, comunidad y fotogalerías.
- Presentación de La Cabina con Luz y Carmona Pics.
- Espacios y llamadas a la acción para anunciantes.
- Enlaces directos a Facebook, Instagram, TikTok y YouTube.
- Metadatos y tarjeta visual para compartir el sitio en redes sociales.

## Desarrollo local

Requiere Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

El sitio estará disponible en `http://localhost:3000`.

## Validación

```bash
npm run build
```

## Estructura principal

- `app/page.tsx`: contenido y componentes de la portada.
- `app/globals.css`: identidad visual y diseño adaptable.
- `app/layout.tsx`: metadatos y tarjeta social.
- `public/images/`: fotografías demostrativas.
- `public/og.jpg`: imagen optimizada para compartir en redes.

Las notas y fotografías actuales funcionan como contenido de demostración y pueden sustituirse por material editorial real.
